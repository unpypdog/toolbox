# 公用信息分享（share-info）设计文档

日期：2026-08-25
状态：已批准

## 背景与目标

工具箱新增「公用信息分享」工具页，用于保存一些可分享给别人的关键数据（如网盘下载链接与访问密码），当前阶段只做「查看 + 整段复制」。未来可能添加分享按钮等功能，不在本次范围内（YAGNI）。

## 数据存储

- 数据写死在页面内嵌 JS 数组中，通过改代码维护
- 每条数据字段：`{ name, url, password }`
  - name：资料库名称，如「技术支持部公共资料库」
  - url：分享链接
  - password：访问密码
- 初始数据放入用户提供的示例（技术支持部公共资料库 + 链接 + 密码 1111）

## 页面结构（tools/share-info/index.html）

- 顶部「← 返回工具箱」链接，指向 `../../index.html`（相对路径，遵守 CLAUDE.md 规则）
- 渲染为卡片列表，每张卡片展示：
  - 名称
  - 分享链接（可点击，新标签页打开，`target="_blank" rel="noopener"`）
  - 访问密码（明文直接展示）
  - 两个复制按钮：「复制链接」复制 URL、「复制密码」复制密码（2026-08-25 修订：弃用整段复制，因手机输入法对整段文本的自动提取不可靠）
- 复制后按钮短暂显示「已复制」，1.5s 后恢复（复用现有工具页样式模式）
- 数据数组为空时显示「暂无分享信息」占位文本
- 视觉风格沿用现有工具页：暖色背景、白色卡片、teal 主色、移动端优先（max-width 420px）

## 首页入口（index.html）

- 添加导航卡片「公用信息分享」
- 图标：📤
- 描述：固定为「网盘链接与密码，一键复制分享」
- 链接：`./tools/share-info/index.html`

## 测试（tests/test_share_info.py）

沿用现有 Playwright e2e 模式（headless chromium、390x844 视口、file:// URL），验证：

1. 页面标题非空
2. 卡片渲染：示例数据对应的卡片名称、链接、密码均可见
3. 「复制链接」「复制密码」按钮存在，点击后有「已复制」反馈（剪贴板断言在 file:// 下受限，见实施备注）
4. 链接可点击且 href 正确
5. 返回链接存在且 href 为 `../../index.html`
6. 首页存在指向新工具的卡片
